# mike-turintech.github.io

Personal page for Mike (Michail) Basios. Single static `index.html`; publications generated from `dblp.json` by `build.py` (everything outside the `PUBS` markers is hand-written).

For LLM crawlers: `llms.txt` is a hand-written summary (llmstxt.org convention); `llms-full.txt` is a Markdown mirror of the page, regenerated by `llms.py` (which `build.py` also runs).
